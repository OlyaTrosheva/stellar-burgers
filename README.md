Stellar Burgers
Учебный проект Яндекс Практикума - веб-приложение космической бургерной, в котором пользователи могут собирать бургеры из ингредиентов и оформлять заказы.
Реализованный функционал:
- Настроила маршрутизацию между страницами приложения, включая динамические маршруты и модальные окна.
- Реализовала глобальное состояние с помощью Redux и получение данных с сервера.
- Реализовала авторизацию пользователей и защиту маршрутов личного кабинета.
- Написала модульные тесты для Redux-редьюсеров на Jest и интеграционные тесты пользовательских сценариев на Playwright.
Технологии:
React, TypeScript, Redux, React Router, Jest, Playwright.

Запуск проекта:

1. Установите зависимости: `npm install`.
2. Создайте файл `.env` на основе `.env.example`.
3. Запустите проект: `npm start`.
